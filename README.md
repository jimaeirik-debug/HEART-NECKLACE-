# Heart & Spoon Necklace landing page

Static one-page site for Vercel.

## Image files to add
Create an `images` folder in the repository and upload these files:

- `hero-woman.jpg` — locked brunette/desert convertible hero
- `necklace-red-car.jpg` — future necklace-on-red-convertible photo
- `heart-spoon-detail.jpg` — close-up showing heart and functional spoon
- `presentation-box.jpg` — packaging photo

Until an image is added, the site shows a styled placeholder so development can continue.

## Deploy on Vercel
1. In Vercel choose **Add New → Project**.
2. Import this GitHub repository.
3. Framework preset: **Other** / static.
4. Deploy.

Every later commit to `main` redeploys automatically.

## Current facts used
- Brass base with gold plating.
- Functional screw-in spoon.
- Adjustable chain.
- Presentation box.
- Product developed from scan files taken from an original necklace.
- Etsy CTA points to listing 1269458252.
